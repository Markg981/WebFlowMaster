Maintenance

The hidden cost of automation, kept under control.

Healed locators

the run proposes a repair when the page changes; a person approves or rejects it

Flaky tests

the ones that change outcome for no reason, with evidence from every attempt

Quarantine

the test keeps running but no longer blocks releases, until it’s stable again

Nothing happens silently: every repair shows in the report and goes live only when published.

Anyone who has tried automation knows the real cost isn’t writing the tests, it’s maintaining them: tests that fail at random and locators that break with every redesign. Here the run proposes the locator repair, but a person approves it. Flaky tests are isolated with the evidence from every attempt, and they can be quarantined: they keep running but don’t block releases. These features arrived after the October presentation.
