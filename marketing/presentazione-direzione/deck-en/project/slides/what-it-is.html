What WebFlowMaster is

One self-hosted platform for every kind of automated test.

Web

recorded in the browser, on Chromium, Firefox and WebKit

API

REST, SOAP, gRPC, WebSocket; import from OpenAPI and Postman

Mobile

Android and iOS with Appium, in the cloud or on our own devices

BDD

versioned Gherkin scenarios, run with Cucumber

Load

virtual users and thresholds, next to the functional tests

Management

requirements, coverage, TestRail, Xray, Zephyr

WebFlowMaster is a platform we install ourselves, on our own servers: the data doesn’t leave. It covers every kind of test we need in one place: web tests, recorded by using the application; APIs, imported from their specifications; Android and iOS apps; BDD scenarios; load tests. And it links everything to the requirements, with coverage calculated and results published to the test management tools people already use.
