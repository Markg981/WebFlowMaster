The problem

Today regression testing costs time at every release, and leaves little evidence.

Test cases in Excel

run by hand, one by one, before every release

Scattered evidence

screenshots in chats and emails, hard to find in an audit

Personal scripts

automation exists where there’s a developer, and leaves with them

Failures to reproduce

“on which machine? with what data?” before anyone can fix it

Where we start from. Test cases live in Excel sheets and are run by hand before every release. The evidence is screenshots in chats or emails. Where there is automation, it’s one person’s scripts, which disappear when that person moves to another project. And when something fails, it has to be reproduced before it can be fixed. [If you have an estimate from your team, for example how many hours of manual regression per release, say it here: it’s the number the pilot will measure.]
