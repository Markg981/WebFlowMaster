The cycle is always the same, for every kind of test. You create the test, by recording it or building it from actions. You organize it into plans, with variables per environment: the same test runs in development, staging and production. You run it when needed. You read the report. And you act: open the issue with the evidence already attached, or export the PDF to attach to the release. The demo follows exactly these five steps.
