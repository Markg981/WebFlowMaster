It doesn’t ask anyone to change tools. The pipeline launches plans with one command, and there are ready-made integrations for Azure Pipelines and the other main CI systems. Failures become issues in Jira or Azure DevOps. Results go to TestRail, Xray or Zephyr. And for applications the server can’t reach, like DMO on a laptop or a staging environment behind a VPN, there’s an agent that runs inside that network and connects outbound.
