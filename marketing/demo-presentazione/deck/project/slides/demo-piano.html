Demo WebFlowMaster · 7

Questo piano contiene i casi NCC che prima erano righe di un foglio Excel. Ogni caso è un test registrato nel browser: niente codice, solo le azioni e le verifiche. Il run non gira sul server, che è in Docker e non vede l'applicazione: gira sull'agente locale su questo portatile, che si collega in uscita verso la piattaforma. È lo stesso meccanismo per un ambiente di staging dietro VPN. Se la demo live fallisce: passare alla scheda con il run già completato.
