{{- if or .Values.postgresql.enabled .Values.redis.enabled }}

WARNING: postgresql.enabled / redis.enabled deploy single-pod stores with no backups and no
replication. They are for evaluating the chart, not for an installation anyone relies on.
{{- end }}
{{- if and (eq .Values.artifacts.store "local") (or (gt (int .Values.api.replicaCount) 1) (gt (int .Values.worker.replicaCount) 1) .Values.api.autoscaling.enabled .Values.worker.autoscaling.enabled .Values.worker.keda.enabled) }}

WARNING: artifacts.store is local with more than one api or worker replica. Every replica
must mount the same ReadWriteMany claims, or report links answer 404; otherwise switch to
artifacts.store: s3.
