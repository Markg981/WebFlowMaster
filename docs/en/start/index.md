# Start here

Three short paths, one per role, each ending with something that works. They link to the full
guides for everything they skip.

| You are…                                | Path                                                   | Time       | You end with                                          |
| --------------------------------------- | ------------------------------------------------------ | ---------- | ----------------------------------------------------- |
| A **tester** (QA, analyst, developer)   | [Your first test in 10 minutes](./qa)                  | 10 minutes | A saved web test, in a plan, with a report            |
| A **DevOps** or release engineer        | [Your first run from a pipeline](./devops)             | 20 minutes | A CI job that runs a plan and fails the build with it |
| An **administrator** of an organization | [Your first organization with single sign-on](./admin) | 45 minutes | Members signing in through your identity provider     |

Not sure which role you have? The sidebar shows it: viewers see tests and results, editors also
create and run them, owners also manage the organization ([Roles](../admin/administration#roles)).

Installing WebFlowMaster itself, on your own servers, is a separate task:
[Installation](../admin/installation).
