# Gespräche und Dashboards

## Über einen Test oder ein Ergebnis sprechen

Öffnen Sie **Kommentare** an einem gespeicherten Web-, API- oder mobilen Test oder an einem
Testergebnis in einem Bericht. Mitglieder, auch Betrachter, können teilnehmen, wenn sie dieses Ziel
lesen dürfen. Gespräche gehören zur aktuellen Organisation und folgen den Projektberechtigungen des
Ziels.

Schreiben Sie einen **Neuer Kommentar**, um ein Gespräch zu beginnen, oder wählen Sie **Antworten**
bei einem offenen Gespräch. Antworten bleiben unter der ursprünglichen Nachricht; es gibt eine
Ebene von Antworten. Nachrichten sind Klartext, bis zu 5.000 Zeichen.

Klappen Sie **Mitglieder erwähnen** auf und wählen Sie die Personen, die Sie erwähnen möchten, bis
zu 20 pro Nachricht. Die Liste enthält die Mitglieder dieser Organisation, die den Test oder das
Ergebnis lesen dürfen. Ihre Benutzernamen erscheinen neben der Nachricht. Einen Benutzernamen nur
zu tippen, wählt keine Erwähnung aus. Beim Bearbeiten einer Nachricht können Sie auch die
ausgewählten Erwähnungen ändern.

Mit **Gespräche filtern** zeigen Sie alle Gespräche, offene Gespräche, erledigte Gespräche oder
Gespräche, **In denen ich erwähnt werde**. Eine Erwähnung in einer Antwort nimmt auch ihr Gespräch
in diesen Filter auf. Erwähnungen sind in der Diskussion und im Filter sichtbar; es gibt keinen
eigenen Posteingang und keine E-Mail-Benachrichtigung.

Der Autor der ursprünglichen Nachricht und die Eigentümer der Organisation können **Gespräch als
erledigt markieren** oder **Gespräch wieder öffnen**. Ein erledigtes Gespräch behält seine
Nachrichten, nimmt neue Antworten aber erst nach dem Wiederöffnen an. Autoren können ihre eigenen
Nachrichten bearbeiten oder löschen; Eigentümer können sie moderieren. Wird eine ursprüngliche
Nachricht mit Antworten gelöscht, bleibt der Platzhalter **Dieser Kommentar wurde gelöscht**: Text
und Erwähnungen verschwinden, die Antworten anderer Mitglieder bleiben lesbar. Eine gelöschte
ursprüngliche Nachricht nimmt keine weiteren Antworten an. Das Löschen eines gespeicherten Tests
entfernt die Diskussionen zu seinen früheren Ergebnissen, die Berichte bleiben verfügbar.

## Dashboards auswählen und teilen

Wählen Sie unter **Übersicht** das Dashboard, das Sie sehen möchten. Sie können mehrere Dashboards
anlegen, umbenennen, duplizieren, löschen und Ihr persönliches Standard-Dashboard wählen. Ein
Duplikat ist eine private Kopie, die Sie unabhängig ändern können. Ihre Standardauswahl gilt für
Ihr Konto; das Löschen eines Dashboards hebt Auswahlen auf, die darauf verwiesen.

| Sichtbarkeit                 | Wer es lesen kann                 | Wer es ändern oder löschen kann                    |
| ---------------------------- | --------------------------------- | -------------------------------------------------- |
| Privat                       | Sein Ersteller                    | Sein Ersteller                                     |
| Mit der Organisation geteilt | Mitglieder derselben Organisation | Sein Ersteller und die Eigentümer der Organisation |

Eigentümer der Organisation können das private Dashboard eines anderen Mitglieds nicht öffnen.
Andere Mitglieder können ein geteiltes Dashboard in eine private Kopie duplizieren. Ein Dashboard zu
teilen, teilt seine Konfiguration: Jeder Leser sieht weiterhin nur die Test- und Projektdaten, auf
die er Zugriff hat. Ein Widget, das für ein Projekt konfiguriert ist, auf das der Leser keinen
Zugriff hat, wird als nicht verfügbar angezeigt, ohne Namen oder Zahlen dieses Projekts.

Ihr bestehendes persönliches Layout wird zu einem privaten Dashboard, mit Reihenfolge und
Sichtbarkeit der Widgets. Dashboards gehören ihrem Ersteller. Wird dieses Mitglied entfernt, werden
seine privaten und geteilten Dashboards gelöscht; Verweise anderer Mitglieder auf diese Dashboards
werden aufgehoben. Duplizieren Sie ein geteiltes Dashboard, bevor Sie seinen Ersteller entfernen,
wenn Sie es behalten müssen. Haben Sie kein gespeichertes Layout, enthält Ihr erstes privates
Dashboard die ursprünglichen fünf Widgets: Kennzahlen, Ausführungsstatus, Trend, anstehende
Zeitpläne und letzte Berichte.

## Widgets bearbeiten

Wählen Sie **Dashboard anpassen** bei einem Dashboard, das Sie verwalten dürfen. Fügen Sie Widgets
hinzu oder entfernen Sie sie, verschieben Sie sie nach oben oder unten, blenden Sie sie ein oder
aus und legen Sie Titel und halbe oder volle Breite fest. Denselben Widget-Typ können Sie mehrmals
hinzufügen, etwa um Projekte oder Zeiträume zu vergleichen. Ein Dashboard enthält höchstens
20 Widgets, ausgeblendete eingeschlossen.

Die verfügbaren Optionen hängen vom Widget ab:

- **Projekt-ID (optional)** beschränkt die Daten über die numerische ID auf ein zugängliches
  Projekt; leer gelassen werden die zugänglichen Daten verwendet.
- **Zeitraum in Tagen** akzeptiert 1–365 Tage.
- **Maximale Anzahl der Ergebnisse** akzeptiert 1–50 Einträge für letzte Berichte oder Zeitpläne.
- **Umgebung** filtert anstehende Zeitpläne.

Speichern Sie das Layout, um Änderungen über Sitzungen hinweg zu behalten. Hat jemand anderes
dieses Dashboard gespeichert, seit Sie den Editor geöffnet haben, meldet das Speichern einen
Konflikt (HTTP 409) und behält Ihren Entwurf. Laden Sie das aktuelle Dashboard neu und wenden Sie
Ihre Änderungen erneut an; der veraltete Entwurf kann die Speicherung der anderen Person nicht
überschreiben.
