# Hier beginnen

Drei kurze Wege, einer pro Rolle, die jeweils mit etwas enden, das funktioniert. Für alles, was sie
auslassen, verweisen sie auf die vollständigen Anleitungen.

| Sie sind…                            | Weg                                                   | Dauer      | Am Ende haben Sie                                                         |
| ------------------------------------ | ----------------------------------------------------- | ---------- | ------------------------------------------------------------------------- |
| **Tester** (QA, Analyst, Entwickler) | [Ihr erster Test in 10 Minuten](./qa)                 | 10 Minuten | Einen gespeicherten Webtest in einem Plan, mit Bericht                    |
| **DevOps**- oder Release-Engineer    | [Ihr erster Lauf aus einer Pipeline](./devops)        | 20 Minuten | Einen CI-Job, der einen Plan ausführt und den Build daran scheitern lässt |
| **Administrator** einer Organisation | [Ihre erste Organisation mit Single Sign-on](./admin) | 45 Minuten | Mitglieder, die sich über Ihren Identitätsanbieter anmelden               |

Sie wissen nicht, welche Rolle Sie haben? Die Seitenleiste zeigt es: Betrachter sehen Tests und
Ergebnisse, Bearbeiter können sie außerdem erstellen und ausführen, Eigentümer verwalten zusätzlich
die Organisation ([Roles](/en/admin/administration#roles), auf Englisch).

WebFlowMaster selbst auf Ihren eigenen Servern zu installieren, ist eine eigene Aufgabe:
[Installation](/en/admin/installation) (auf Englisch).
