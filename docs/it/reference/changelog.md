# Note di rilascio

Che cosa è cambiato in WebFlowMaster, versione per versione. Le note di rilascio sono scritte in
inglese, in un solo file (`CHANGELOG.md` alla radice del repository), e questa pagina lo mostra così
com'è. Il formato segue [Keep a Changelog](https://keepachangelog.com/it-IT/1.1.0/): ogni versione
elenca le novità (_Added_), i cambiamenti (_Changed_), le correzioni (_Fixed_) e le correzioni di
sicurezza (_Security_); _Unreleased_ è ciò che è già su `main` e uscirà con la prossima versione.
