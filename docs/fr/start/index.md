# Par où commencer

Trois parcours courts, un par rôle, qui se terminent chacun par quelque chose qui fonctionne. Ils
renvoient aux guides complets pour tout ce qu'ils laissent de côté.

| Vous êtes…                              | Parcours                                                            | Durée      | À la fin, vous avez                                            |
| --------------------------------------- | ------------------------------------------------------------------- | ---------- | -------------------------------------------------------------- |
| **Testeur** (QA, analyste, développeur) | [Votre premier test en 10 minutes](./qa)                            | 10 minutes | Un test web enregistré, dans un plan, avec un rapport          |
| Ingénieur **DevOps** ou de release      | [Votre première exécution depuis un pipeline](./devops)             | 20 minutes | Un job de CI qui exécute un plan et fait échouer le build avec |
| **Administrateur** d'une organisation   | [Votre première organisation avec authentification unique](./admin) | 45 minutes | Des membres qui se connectent via votre fournisseur d'identité |

Vous ne savez pas quel rôle vous avez ? La barre latérale le montre : les lecteurs voient les tests
et les résultats, les éditeurs peuvent aussi les créer et les exécuter, les propriétaires gèrent en
plus l'organisation ([Roles](/en/admin/administration#roles), en anglais).

Installer WebFlowMaster lui-même, sur vos propres serveurs, est une tâche à part :
[Installation](/en/admin/installation) (en anglais).
